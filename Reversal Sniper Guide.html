🎯 Reversal Sniper — User Guide

MMT scriptDelta pressureTape + OI + Liq confluence

Reversal Sniper is an MMT (Momentum Trader Terminal) indicator that detects impulse extremes in rolling delta pressure — firing in realtime as the extreme forms (no 2-bar confirmation wait) — and scores them against a confluence cluster of tape, open interest and liquidation data. It fires a square marker at the extreme price and an alert with the full score breakdown — built for catching counter-trend reversal zones at climax points.

1 · How to use it

Install & load

  1. Open MMT → Indicators → load Reversal Sniper.js from the local indicators folder.
  2. Attach it to a chart. Confirmed reversal signals are square markers overlaid directly on price, and the script’s own pane shows a live dashboard:
  • Delta pressure histogram — rolling delta as % of adaptive scale, green/red while an impulse state is active, dim when neutral.
  • Entry (dashed) / Exit (dotted) hysteresis bands.
  • State line — current state machine value (±100) in the same green/red/neutral colors.
  • Score histogram — most recent impulse evaluation score as % of the honest max (7 when every component is on and its feed is present; purple, persists between setups).
  • Component status bars — Tape, Divergence, Absorption, OI, Liq, Wick, Level (each 0/100, persists between evaluations).
  1. For the Positioning cluster (OI / liquidations) to work, the connected exchange must provide those feeds (e.g. Binance Futures, Bybit). The indicator degrades gracefully if they are missing.

Reading a signal

  • Red square at a price high → bullish impulse climaxed (buyers exhausted) → expect a bearish reversal. Anticipate short entries or long exits there.
  • Green square at a price low → bearish impulse climaxed (sellers exhausted) → expect a bullish reversal. Anticipate long entries or short exits there.
  • The marker sits at the exact extreme price of the impulse, so it doubles as a natural invalidation level: a clean break beyond it argues the reversal thesis is wrong.
Tip: the alert payload tells you why a signal fired (components field, e.g. tape,divergence,liq,wick). Log it to your automation and only act on signals containing the components you trust most.

2 · The logic behind it

Step 1 — Delta pressure core (ported from Delta Candle Pressure)

  1. Rolling delta — a rolling sum of buy/sell volume delta over the core preset's delta period (Automatic/Scalp 5m: 12 bars, Scalp 1m: 10); the raw "who is in control" measure.
  2. Adaptive scale — each bar's expected delta magnitude is estimated from the core preset's lookback window (Automatic/Scalp 5m: 240 bars, Scalp 1m: 120): a natural split found via Otsu thresholding (separating normal noise from bursts) clamped between percentile rails (68th–88th), then smoothed with an asymmetric EMA (fast up, slow down) so the scale keeps up with expansions but doesn't crash on quiet periods.
  3. State machine — rolling delta vs. adaptive entry/exit thresholds produces a trinary state (+1 bull / 0 neutral / −1 bear) with hysteresis: you need a big move to enter a state, a small move to leave it. The neutral-exit band (what fraction of the entry you must fall below to exit) is set by the core preset (0.65 Automatic, 0.55 Scalp 1m, 0.65 Scalp 5m).
  4. Confirmed / potential impulse — for backfill, a state flip (e.g. +1 → 0/−1) two bars later confirms the impulse is over; in realtime the marker fires the moment the forming bar pushes a new extreme inside an active impulse (or, at an established level, the moment the state exits mid-bar) — no waiting for confirmation. The impulse's start is walked back through the state run, its peak delta must exceed the core preset's climax ratio of the adaptive scale (75% Automatic/Scalp 1m, 85% Scalp 5m — a genuine climax, not noise), and the extreme price is the highest high / lowest low of the run.

Honest counting: each component reads a different fact — tape reads participation frequency (trade-count burst), absorption reads size and neutrality (volume Z-scores + |Δ|/vol + range) — so they no longer share a score point. The score counts every enabled component whose feed is present (max 7), while the component bars show each raw trigger. Fresh-money veto: if open interest grew strongly across the impulse (≥ the OI growth veto %, default 5% — 3% on Strict, 7% on Aggressive), the signal is suppressed regardless of score: new fuel added in the impulse direction argues against an imminent reversal.

Step 3 — Firing rules

  • Gate: confirmed impulse extreme (always required).
  • Cluster requirements: ≥ 1 component from the Flow cluster and ≥ 1 from the Positioning cluster — so a signal is never just "a big candle" nor just "a big liquidation".
  • Minimum score: total score must reach the preset's threshold (Balanced 3, Strict 4, Aggressive 2 by default).
  • Fresh-money veto: strong OI growth (≥ the veto %) across the impulse blocks the signal no matter the score.
  • Dedup + cooldown: the same impulse fires once, and new signals wait the cooldown period after the last one — no marker spam on the same extreme.
  • Realtime (live chart): signals are evaluated on every tick of the forming bar — there is no bar − 2 confirmation wait. The moment the forming bar pushes a new extreme inside an active impulse (higher high / lower low), the marker prints immediately at the current bar, no chart reload needed. If the reversal happens at an established level instead (the forming bar doesn't make a new extreme), the marker fires as soon as the state machine exits the impulse mid-bar. On reload/backfill the marker is re-anchored at the exact extreme price/bar.

Degradation & limits

  • No OI feed → that component silently drops out and the positioning requirement is satisfied by liquidations alone (or degrades to flow-only detection if both are off).
  • No STAT feed → liquidation component drops out the same way.
  • The script is a reversal zone locator, not a full entry system — it does not size positions, manage risk, or decide direction after the extreme. Use the marker as your trigger zone + invalidation, and combine with your own risk rules.
Preset tuning advice: start on Balanced. If signals feel noisy on your timeframe, move to Strict; if too rare, Aggressive. Then fine-tune with Custom — the two most impactful knobs are the tape Z-score (activity threshold) and OI net-change Z-score (fuel threshold).
